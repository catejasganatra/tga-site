# Tejas Ganatra & Associates – static site

Single-page static site (HTML/CSS, one tiny script for the mobile menu). No build step, no framework.

Preview: `python3 -m http.server` then open http://localhost:8000

Design: "The Ledger" – paper/ink/bottle-green palette, Newsreader + Hanken Grotesk + IBM Plex Mono,
ledger-style services table and accountant's double rules. No scroll animations.
